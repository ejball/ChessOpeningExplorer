# Wikibooks processing manifest

This records source pages examined for the app’s opening explanations. A page in `complete-book.json` that is not listed here is **unprocessed**. The page title and revision identify the exact version examined; a refreshed snapshot may contain a newer revision.

Use these statuses:

- **explained** — used for one or more app explanations; the move sequence identifies the current explanation.
- **no-useful-prose** — examined, but has no suitable explanatory prose; explain why in Notes.
- **duplicate-position** — examined, but duplicates a position already covered; identify the other sequence in Notes.
- **needs-review** — examined, but cannot yet be used confidently; explain what remains to be checked in Notes.

Add a row when a page is processed. Use `—` for a move sequence if the page has none. Keep the examined revision pinned in `chess-opening-theory.json` for any explanation, and update the row when processing a newer revision. A page can have more than one row if it supports distinct explanations.
